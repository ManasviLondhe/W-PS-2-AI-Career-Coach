# SkillProof AI — Live Demo & Judging Walkthrough
**W-PS-2 AI Career Coach | Hackathon Presentation Script**

---

## Central Narrative

> *"A resume tells a story. Your code shows the evidence.*  
> *SkillProof AI connects real job requirements to verifiable code artifacts in GitHub—and automatically reassesses your skills every time you ship a commit."*

---

## 3-Minute Live Demo Flow

### Act 1: The First Impression (Landing Page & Proof Engine)
1. Open `http://localhost:5173/` in your browser.
2. Highlight the **Proof Engine visual**:
   - Left: **Job Requirements** (Java, SQL, REST APIs).
   - Center: **Repository Evidence** (File paths, commit SHA, real code excerpts).
   - Right: **Skill Assessment** (Demonstrated vs. Not demonstrated in analyzed scope).
3. Click **"Analyze my portfolio"** to enter the workspace dashboard.

### Act 2: Dashboard Command Center (`/dashboard`)
1. Point to the **Coverage Score Gauge** and explain that the score is deterministic and formula-backed, not arbitrary AI optimism.
2. Note the **Active Assessments** card and the **Real-Time Sync Pill** in the top navigation indicating live SSE connection to the background worker.

### Act 3: Job Discovery (`/jobs`)
1. Navigate to **Job Explorer**.
2. View the pre-seeded **Stripe Backend Software Engineer** and **Figma Full Stack Engineer** postings.
3. Click into **Stripe Backend Software Engineer**:
   - Inspect the required skills: `Java`, `SQL`, `REST APIs`, `Git`, `Testing`.
   - Point out the direct source link back to Stripe.
4. Click **"Compare with my repository"** to navigate to the assessment matrix.

### Act 4: The Assessment Workspace (`/assessments/:id`)
1. Point out the **3 strictly enforced statuses**:
   - `Demonstrated` (Forest green badge with verified proof).
   - `Partially demonstrated` (Warm amber badge with limitation notice).
   - `Not demonstrated in analyzed scope` (Neutral slate badge; never uses judgmental language like "You lack skill").
2. Click any skill row (e.g. `SQL` or `Testing`) to open the **Skill Detail Drawer**:
   - Point out the **Grounding & Limitations**: "Assessment strictly reflects code analyzed at commit XXXXXXX".
   - Point out the **Actionable Recommendations** generated by the AI Coach.

### Act 5: Actionable Roadmap (`/assessments/:id/gaps`)
1. Click **Skill Gaps** in the sidebar.
2. Review the structured blueprints:
   - What is missing from the analyzed scope.
   - Recommended next project task (e.g. adding database schema or unit tests).
   - Exact artifacts that would provide verifiable evidence.

### Act 6: Commit-to-Reassessment Showcase (`/activity` & `/assessments/:id/history`)
1. Open the terminal and run the end-to-end integration test:
   ```bash
   npm test
   ```
2. Show the test output where:
   - Initial commit had Java present and SQL missing.
   - Commit #2 added `database/queries.sql`.
   - Background worker detected the new commit SHA and affected skill `SQL`.
   - Revision #2 was created automatically with SQL transitioning to `Demonstrated`!
   - Revision #1 remains intact and accessible in the revision history.
3. Show the **Assessment History** page showing Revision 1 vs Revision 2 side-by-side!

### Act 7: Settings & Health Probes (`/settings`)
1. Open **Settings** to show live system diagnostics:
   - Backend API uptime and status.
   - MongoDB database connection.
   - GitHub API rate limit counter (55/60 remaining).
   - LLM Engine provider configuration.
